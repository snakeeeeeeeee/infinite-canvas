# Canvas 生成错误展示设计

## 问题

SuperToken 异步任务失败时已经返回结构化的 `error.code` 和 `error.message`，但前端轮询只保留 `message`，画布结束批次时又将具体错误覆盖为“全部图片生成失败”，导致节点无法说明真实原因。

## 处理

- SuperToken 图片和视频任务失败时保留原始 `message`，并在下一行附加 `code: <error.code>`。
- 画布批次全部失败时使用首个真实错误作为根节点错误，不再替换为通用文案。
- 单图、多图槽位、刷新恢复和重试继续复用现有 `errorDetails` 字段，不增加新的持久化结构。
- 节点失败态允许错误内容换行并限制最大高度，超长错误在节点内部滚动，不改变节点尺寸。
- 没有结构化错误信息时继续使用现有通用失败文案。

## 验收

- `new_api_error` 与服务端原始安全拦截消息同时显示。
- 单图失败不再只显示“全部图片生成失败”。
- 多图全部失败时每个失败槽位保留对应错误，折叠主节点显示首个错误。
- 长消息不会溢出节点或遮挡重试按钮。
