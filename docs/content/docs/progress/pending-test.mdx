# Pending Tests

The current release needs manual verification in these areas:

- English and Simplified Chinese switching across navigation, settings, titles, descriptions, Ant Design components, and persisted preferences.
- Global Dropdown, Menu, Select, Cascader, and TreeSelect popup backgrounds, hover states, and selected states in both light and dark themes.
- Canvas node resize stability, prompt scrolling, generated-prompt restoration, image editing, drag-and-drop references, and generation configuration.
- Canvas Agent startup, MCP status, model and permission controls, approvals, version reporting, diagnostics, streaming responses, history consistency, multi-tab isolation, and local Skill management.
- Agent header tabs in English and Chinese at different panel widths; labels should collapse to icons and counts before either edge is clipped.
- Agent message layout, Markdown, code blocks, attachments, token statistics, progress timelines, command groups, and scroll-follow behavior.
- Prompt Center layout, source synchronization, search, asset insertion, prompt detail dialogs, and compact split-layout prompt pickers in the image and video workbenches.
- Settings import/export, Volcengine Ark protocol handling, and WebDAV-related configuration.
- Local source Docker Compose deployment should serve the frontend at host port 10001 while the container continues listening on port 3000.
- SuperToken provider setup with fixed mainland/global regions, separate image/video Model API Keys, a Resource API Key, partial or full model refresh, and video choices limited to Kling, Seedance 2.0, and MiniMax H3.
- SuperToken image generation/edit and video frame/images/media modes across the image workbench, video workbench, and Canvas, including durable polling recovery, local stop behavior, protected result downloads, and local Blob persistence.
- Switching among Kling, Seedance, and MiniMax H3 should retain all reference media while resetting resolution, duration, aspect ratio, reference mode, and audio to the new model defaults; resolution uses the lowest account-available SKU and duration uses the shortest supported value.
- SuperToken browser media upload and real Adobe/Leonardo generation have been verified after enabling the deployed Canvas origins, `PUT`, and `Content-Type` in the target R2 bucket CORS policy.

The Chinese version contains the complete item-by-item acceptance checklist.
